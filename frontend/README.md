# Frontend de Control de Maquinaria

Instalación, ejecución, estructura, cuentas temporales locales y validación: [README principal](../README.md).

Todos los comandos npm se ejecutan desde esta carpeta. `src/` contiene la aplicación modular y sus pruebas unitarias; `pruebas/` contiene pruebas de interfaz y datos temporales que no se incluyen en producción. `.env.example` documenta `VITE_API_URL`.
